# Franksomi Records, v14

A public **website and online shop** (with order tracking up to delivery) joined to a phone-friendly web app that replaces Excel record books for a repair, sales, printing and field-installation business:
repairs and job cards, field jobs, sales, printing & cyber, stock, suppliers, quotations / invoices / receipts, income and
expenses, end-of-day cash-up, monthly and yearly reports, M-Pesa payment prompts (Safaricom Daraja and Kopo Kopo till),
M-Pesa statement reconciliation, customer tracking page, customer SMS, staff roles and an activity log.

It is a plain static website (vanilla JavaScript, no build step) plus a Postgres database with login and a few small
serverless functions. Everything is open for you to host wherever you like: see `docs/DEPLOY_ANYWHERE.md`.
